## Session

### Session Title
Serverless AI Factory: An Autonomous Dev Pipeline on AWS

### Description (400–1500 chars)
I run an AI agent system that watches GitHub issues, plans the work, writes the code, and opens pull requests — fully autonomously, on scale-to-zero AWS. A webhook hits API Gateway, EventBridge routes the event, and Lambda spins up agents on demand that drop back to zero when idle. In this session I'll show the real architecture: EventBridge orchestration, Step Functions for long-running agent workflows, and how I keep multi-agent memory on stateless infrastructure using DynamoDB and a vector store. Then the honest part — the cost surprises (LLM tokens dwarf the infra bill), the cold-start vs. agent-context-loading trade-off, and the failure modes nobody warns you about: circular agent loops, runaway token spend, and debugging across invocations in CloudWatch. I'll close with a live demo from a fresh GitHub issue to a merged PR in a few minutes. This is for builders who want to ship production AI agents with burst economics instead of idle servers — what works, what breaks, and what it actually costs.
