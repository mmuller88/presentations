Spine

Start with the question procurement asks

Is eu-central-1 enough — or do you need partition aws-eusc?

  • ESC GA Jan 2026 · region eusc-de-east-1 (Brandenburg)
  • SCHUFA, ITZBund, SAP on it — but most builders still on standard AWS
  • Wrong answer costs months; right answer is workload-specific

Decision framework

Three buckets

1 · eu-central-1

EU residency enough · full catalog · most customers

2 · ESC workloads

Sovereign partition required · hybrid phased migration

3 · Full sovereign stack

ESC + on-prem / national cloud — deliberate, rare

For builders

What breaks in migration

  • IAM — new identities, no 1:1 copy
  • ARNs — partition aws-eusc
  • Route 53 — common pain point
  • Billing — partition-scoped
  • CI/CD — separate creds/pipelines
  • Services — verify matrix first
~5 min total with next slide. Marketing skips this — builders feel it at deploy time.
